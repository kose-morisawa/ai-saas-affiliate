# ASP 規約メモ（随時更新）

## A8.net
- AIで生成した記事は明示的禁止規定なし（2025年現在）
- ただし特定出稿主からの個別審査で「AIコンテンツ不可」と指定されるケースあり
- **景表法対応**：2023年10月施行のステマ規制に基づきPR表記必須
- PR表記位置：記事の最上部（スクロール前に見える位置）
- 禁止：直接URL転送・リダイレクト経由の送客

## バリューコマース
- 同上。景表法対応のPR表記必須

## Amazon アソシエイト
- スクリーンショット（Amazonページ画像）の転載禁止
- Amazonロゴ・商品画像の無断使用禁止
- 2025年11月27日改定：Creators API導入、AIコンテンツへの追加ガイドライン
- サインアップ後180日以内に3件以上の適格販売が必要
- **報酬：0%〜10%（カテゴリによる）**

## エックスサーバー（A8経由）
- 公式スタンダード：5,000円 / プレミアム：7,500円 / ビジネス：10,000円
- XServerビジネス：15,000円
- ConoHa WING：最大10,000円（WINGパック）
- Adobe CC：初月払いプランの85%（約10,523円）
- Notion：最初の12ヶ月 全支払いの50%（上限なし）

## 注意
- 金融系ASP（SBI証券・楽天証券等）の報酬額はブログへの直接掲載を禁止しているものが多い
- 仮想通貨関連は規約変更頻度が高く都度確認が必須
